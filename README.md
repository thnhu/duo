# Duo

Công cụ học từ vựng Anh – Đức (Breadth & Depth). Xem [`docs/vocab-tool-spec.md`](docs/vocab-tool-spec.md) và [`docs/user-journey.md`](docs/user-journey.md) để biết đầy đủ yêu cầu; [`CLAUDE.md`](CLAUDE.md) tóm tắt các nguyên tắc cứng.

## Phát triển

```bash
npm install
npm run dev
```

## Build & preview (kiểm tra PWA)

```bash
npm run build
npm run preview
```

Deploy tự động lên GitHub Pages qua `.github/workflows/deploy.yml` khi push lên `main`.
